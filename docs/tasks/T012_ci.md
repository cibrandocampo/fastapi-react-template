# T012 — Continuous integration

**Plan**: docs/plans/template-base.md · **Depends on**: T011

## Objective
Every PR and push to main runs lint, unit tests with coverage, E2E and the image build; images are
pushed to Docker Hub only when the repository has the credentials.

## Step 1 — `ci.yml`
Jobs (all through Docker, as locally):
- `backend`: build the dev backend, ruff check/format, pytest with coverage against the dev db.
- `frontend`: npm ci, lint, format check, vitest coverage.
- `e2e` (needs both): `make e2e`, upload the Playwright report on failure.
- `audit` (non-blocking): pip-audit, `npm audit --omit=dev --audit-level=high`.
- `image` (needs e2e): buildx multi-arch (amd64, arm64) with `APP_VERSION` from `git describe`; push
  only when `DOCKERHUB_USERNAME` and `DOCKERHUB_TOKEN` secrets exist and the event is a push to main
  (`latest`) or a published release (`<version>`, `stable`); otherwise build only (amd64, no push).
  Image name from the `DOCKER_IMAGE` repository variable.
`permissions: contents: read`; concurrency cancels superseded PR runs only.

## Step 2 — Other workflows
`weekly-rebuild.yml` (Mondays, no cache, same push condition), keep `sync-disposable-email-domains.yml`,
`.github/dependabot.yml` (pip, npm, docker, github-actions; weekly).

## DoD
1. Workflows parse; `actionlint` (in its Docker image) clean.
2. CI green on the PR, with the image job building without pushing (no secrets in this repo).
